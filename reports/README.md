# SOC Investigation Reports

## Overview

This folder contains investigation reports created during the Enterprise SOC Analyst Lab.

Each report documents a security event, explains the investigation process, identifies the evidence collected, and summarizes the findings.

The objective of these reports is to demonstrate practical SOC analyst skills including:

- Alert Investigation
- Log Analysis
- Endpoint Investigation
- Threat Hunting
- Detection Engineering
- Incident Response
- Malware Analysis
- Webhook Automation
- Ticket Management

---

## Investigation Reports

| Report | Description |
|---------|-------------|
| Windows RDP Investigation | Investigation of Windows Remote Desktop authentication events |
| Linux SSH Investigation | Analysis of SSH authentication logs from Ubuntu |
| Mythic C2 Incident Response | Investigation of Mythic C2 callback and attacker activity |
| Malware Detection Incident | Analysis of malware execution detected by Elastic Defend |
| osTicket Webhook Incident | Automatic ticket generation from Kibana alerts |
| Lessons Learned | Summary of findings and improvements |

---

## Investigation Workflow

1. Alert Generated
2. Alert Triage
3. Evidence Collection
4. Log Analysis
5. Threat Hunting
6. Root Cause Analysis
7. Incident Documentation
8. Lessons Learned

---

These reports simulate the investigation workflow followed by Security Operations Center (SOC) analysts in enterprise environments.
