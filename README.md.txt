### SOC Analyst Enterprise Lab

An enterprise-style Security Operation Center (SOC) home lab built on Vultr Cloud to simulate real-world cyber attacks, endpoint monitoring, threat detection, command-and-control activity, incident response, and ticket management suing the Elastic Stack.
 
Project Overview
----------------

This repository documents the design, deployment, configuration, and operation of a complete enterprise-style Security Operation Center (SOC) laboratory.

The objective of this project was to build a realistic SOC environment capable of detecting, investigating, and responding to security events across Windows and Linux endpoints while gaining practical experience with modern SOC technologies.

The environment was deployed on Vultr Cloud using a private Virtual Private Cloud (VPC) network. Multiple servers were configured to simulate an enterprise infrastructure, including Elastic Stack, Fleet Server, osTicket, Kali, Linux, and Mythic Command and Control (C2).

The lab simulates the complete Security Operation Center workflow from attack simulation to detection, investigation, ticket generation, and incident response.

# Attack Simulation

A realistic attack simulation was performed to validate the monitoring and detection capabilities of the SOC environment.

## Attack Workflow

1. Deploy Mythic Command and Control (C2).
2. Generate an agent payload.
3. Execute the payload on the Windows endpoint.
4. Establish a successful callback to the Mythic server.
5. Execute post-exploitation commands, including:
   - whoami
   - ipconfig
   - hostname
6. Elastic Agent continuously monitors endpoint activity.
7. Elastic Defend detects suspicious behavior generated by the payload.
8. Kibana generates security alerts.
9. A Webhook Connector forwards the alert to osTicket.
10. The SOC Analyst investigates the incident using Elastic Security dashboards and endpoint telemetry.
